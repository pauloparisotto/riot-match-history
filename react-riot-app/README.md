# Riot Profile Tracker

Riot Profile tracker is a profile tracker that utilizes Riot Games API to see your match history from League of Legends. It's a project that you can search for a player using your Riot ID and retrive recent matches, it displays the champion played, kda, and match result.

This project was created using mainly JavaScript, React, and the Riot API. And its currently under development.

## Riot API

This project uses the Riot Games API. An API key is needed to run this project.
